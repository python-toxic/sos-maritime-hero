# Sos Maritime Hero

Create a high-fidelity desktop website hero UI for SOS India, using the attached original hero screenshot as the strict reference for layout, typography, spacing, and styling.

Important: Use a completely plain white background. Do NOT include any ship, harbor, scenery, background image, gradients, or textures. The ship background will be added separately using CSS.

Recreate only the navbar and left-side hero content: SOS India logo, navigation links, “Get in touch” button, eyebrow text “MARITIME SAFETY / SHIP RECYCLING / COMPLIANCE”, headline “Safer Seas / A Cleaner Tomorrow”, supporting description, primary CTA “Explore Our Services”, and secondary “Watch Our Approach” button.

Use DM Serif Display for headlines and Inter for all other text. Maintain the original deep navy, muted blue accents, refined spacing, and premium maritime-corporate aesthetic. Keep the right half mostly empty to accommodate the separately added ship background.

Canvas: 16:7 aspect ratio, desktop viewport, crisp high-resolution UI. No extra sections or invented content.
